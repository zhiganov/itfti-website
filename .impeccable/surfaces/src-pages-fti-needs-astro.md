# Organisation-needs format and publisher guide

Mode: Read. Readers are organisations publishing practical requests for skilled
help, plus contributors and tool builders interpreting those requests. The task is
to understand the fields, download a valid example and publish an honest file.
The user selected public publication at itfti.org under CC0. Server implementation,
query contracts, hosted intake, outreach and payment remain outside this surface.

## Direction contract

THESIS: Extend the existing FtI documentation, with a clear distinction between
requests for work and offers of grants. Comprehension leads; no new visual world.

OWN-WORLD: Preserve DESIGN.md's seal-red on paper, slab headings, reading face,
square controls and shared section grid. Reuse the existing copy block and links.

STORY: An organisation sees what to publish, which money is for labour versus
other costs, and how to keep the record current. A listing creates no agreement.

FIRST VIEWPORT: Existing masthead; title and draft/licence statement on the left,
plain purpose and schema/example/guide links on the right. Mobile stacks in the
existing order. A short contents list leads into the field reference.

FORM: Existing FtI reading composition, extended to a sibling format and guide.
seed: none (inherited composition; no new direction round).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
